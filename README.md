# AI Security Risk Scanner

Experimental cybersecurity project focused on helping small businesses identify digital security risks using automation and AI.

## Goals

* Detect common security vulnerabilities
* Generate automated reports
* Prioritize risks using AI
* Make cybersecurity more accessible for SMEs in LATAM

## Features (planned)

* Automated risk analysis
* AI-generated security reports
* Vulnerability prioritization
* Security scoring dashboard

## Tech Stack

* Python
* FastAPI
* OpenAI API
* PostgreSQL
* React

## Vision

Democratize cybersecurity tools for small businesses in Latin America.
